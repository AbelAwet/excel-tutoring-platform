# Image Assets

Place your service images here according to the following structure:

## Directory Structure:
```
images/
├── hero/
│   └── online-tutoring-session.jpg (Student in yellow shirt with laptop)
├── services/
│   ├── in-person-tutoring.jpg (Tutor and student at desk)
│   ├── group-learning.jpg (Modern classroom setting)
│   └── study-group.jpg (Small group with charts)
├── subjects/
│   ├── math-tutoring.jpg (Math lesson with whiteboard)
│   ├── coding-tutoring.jpg (Coding instruction)
│   └── traditional-learning.jpg (Home tutoring scene)
└── about/
    └── team-collaboration.jpg (Team working together)
```

## Image Specifications:
- **Format**: JPG or WebP
- **Hero Images**: 1920x1080px, < 200KB
- **Service Images**: 800x600px, < 100KB
- **Quality**: 85% for JPG
